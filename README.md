# Marutham Stores — eCommerce Platform

A full-stack eCommerce platform with product, category, and order management, backed by a dedicated admin dashboard.

**Live Demo:** [maruthamstores.com](https://www.maruthamstores.com/)

## Overview

Marutham Stores is a responsive online storefront where customers can browse products and place orders, while admins manage inventory, categories, and orders through a dedicated dashboard.

## Features

- 🛒 Product and category browsing (customer-facing storefront)
- 📦 Full CRUD for products, categories, and orders
- 📊 Admin dashboard for inventory and order management
- 📱 Responsive, mobile-friendly design
- 🔌 REST API-driven architecture

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL

## My Role

- Built end-to-end CRUD modules for products, categories, and orders
- Developed the admin dashboard for inventory and order management
- Integrated MySQL for persistent, relational data storage
- Built a responsive storefront UI optimized for mobile
